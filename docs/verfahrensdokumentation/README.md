# Verfahrensdokumentation – Vorlage für Betriebe mit EasyBau

Nach den GoBD (BMF-Schreiben vom 28.11.2019, Rz. 151 ff.) muss jeder Betrieb, der Bücher und Aufzeichnungen elektronisch führt, eine **Verfahrensdokumentation** haben: Sie beschreibt, wie Belege entstehen, verarbeitet, aufbewahrt und wiedergefunden werden – so, dass ein sachverständiger Dritter (z. B. Betriebsprüfer) das Verfahren in angemessener Zeit nachvollziehen kann.

**Diese Vorlage ist keine Rechtsberatung.** Weil Sie EasyBau selbst betreiben, sind Sie für die Verfahrensdokumentation verantwortlich (siehe auch [Betriebsdokumentation](../self-hosting/README.md)). Die Vorlage beschreibt, was EasyBau technisch sicherstellt; was nur Sie wissen, steht in doppelten eckigen Klammern `[[…]]` und muss ausgefüllt werden. Besprechen Sie das Ergebnis mit Ihrer Steuerberatung.

| Teil | Inhalt |
|---|---|
| [1. Allgemeine Beschreibung](01-allgemeine-beschreibung.md) | Unternehmen, Zuständigkeiten, eingesetzte Programme, Überblick der Abläufe |
| [2. Anwenderdokumentation](02-anwenderdokumentation.md) | Wie Belege in EasyBau entstehen: Angebot, Auftrag, Aufmaß, Rechnung, Storno, Zahlungen, Mahnungen, Eingangsrechnungen |
| [3. Technische Systemdokumentation](03-technische-systemdokumentation.md) | Datenhaltung, Unveränderbarkeit, Änderungsprotokoll, Nummernkreise, E-Rechnung, Belegarchiv, Schnittstellen |
| [4. Betriebsdokumentation](04-betriebsdokumentation.md) | Server, Updates, Sicherung, Wiederherstellung, Überwachung, Prüferzugang |
| [5. Internes Kontrollsystem](05-internes-kontrollsystem.md) | Rollen und Rechte, Kontrollen, Abstimmungen |
| [6. Datenschutz und Löschkonzept](06-datenschutz-loeschkonzept.md) | Verzeichnis von Verarbeitungstätigkeiten, technische und organisatorische Maßnahmen, Löschkonzept |

**Pflege:** Ändern sich Abläufe, Zuständigkeiten oder die eingesetzte EasyBau-Version wesentlich, wird die Dokumentation fortgeschrieben. Alte Fassungen werden wie Belege aufbewahrt (GoBD Rz. 154: so lange wie die Unterlagen, die mit ihnen erstellt wurden). Halten Sie dazu unten fest, welche Fassung ab wann gilt.

| Fassung | Gültig ab | Änderung | Verantwortlich |
